# Air Quality Analysis using Excel

## Project Overview
This project explores air quality data using Microsoft Excel. The objective is to analyse pollutant measurements and environmental conditions through KPI cards, PivotTables, and charts.

## Tools Used
- Microsoft Excel
- Excel Tables
- Excel Formulas
- PivotTables
- Excel Charts

## Project Highlights
- Cleaned the dataset by replacing the `-200` missing-value marker with blank cells in measurement columns.
- Created a combined DateTime column.
- Developed 4 KPI cards to summarise key measurements.
- Created 4 charts to explore air quality and environmental trends.
- Used PivotTables to calculate average pollutant levels and monthly humidity.

## Dashboard KPIs
- Total Records
- Average CO
- Average NO₂
- Average Temperature

## Visualisations
1. Hourly Carbon Monoxide (CO) Trend
2. Hourly Temperature Variation
3. Average Pollutant Concentration
4. Monthly Average Relative Humidity

## Dataset
**Source:** UCI Machine Learning Repository

**Dataset:** [Air Quality Dataset](https://archive.ics.uci.edu/dataset/360/air+quality)

The dataset contains hourly air quality measurements collected from an air quality monitoring station.

## Key Learning
Through this project, I practised data cleaning, Excel formulas, PivotTables, chart creation, and dashboard design.
